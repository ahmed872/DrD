# سكربتات إدارية — تُشغَّل يدوياً

هذه السكربتات **لا تعمل تلقائياً ولا تُنشر مع التطبيق**. كل واحد منها يُشغَّل
مرة واحدة، من جهازك، بصلاحيات Admin SDK.

## قبل أي تشغيل

1. خُذ نسخة احتياطية من Firestore
   (Firebase Console ← Firestore ← Import/Export).
2. حمّل مفتاح حساب الخدمة:
   Project Settings ← Service accounts ← Generate new private key.
3. ثبّت الاعتماد وشغّل بـ `--dry-run` أولاً وراجع الناتج.

```bash
npm i firebase-admin
export GOOGLE_APPLICATION_CREDENTIALS=/path/to/serviceAccount.json
```

## `backfill_phone_index.js`

**متى؟** إذا كانت هناك حسابات أُنشئت قبل وجود مجموعة `phone_index`.

**لماذا؟** تسجيل الدخول يترجم الرقم إلى بريد عبر `phone_index` حصراً. الحساب
الذي لا مدخل له في الفهرس **لا يستطيع صاحبه الدخول إطلاقاً**، ويرى رسالة
«رقم الجوال أو كلمة المرور غير صحيحة» وكأنه أخطأ في كلمة المرور.

كان في التطبيق مسار احتياطي يُفترض أنه يهاجر هذه الحسابات تدريجياً، لكنه
مرفوض من قواعد الأمان ولم يعمل ولا مرة. أُزيل، وهذا السكربت بديله.

**كيف تعرف إن كنت تحتاجه؟** قارن عدد مستندات `users` بعدد مستندات
`phone_index` في وحدة التحكم. أي فارق = حسابات محبوسة.

```bash
node scripts/backfill_phone_index.js --dry-run
node scripts/backfill_phone_index.js
```

لا يكتب فوق أي مدخل قائم؛ التعارضات تُطبع لمراجعتها يدوياً.

## `strip_slot_patient_ids.js`

**متى؟** مرة واحدة، **بعد** نشر نسخة التطبيق المحدَّثة.

**لماذا؟** كانت مستندات `slots` تحمل `patientIds` — ومجموعة `slots` مقروءة
لكل مستخدم مسجَّل (وهذا ضروري لعرض الأوقات المتاحة). النتيجة أن أي مستخدم
كان يستطيع معرفة مَن حجز عند أي طبيب ومتى.

التطبيق لم يعد يكتب الحقل، والقاعدة تمنعه في الخانات الجديدة. هذا السكربت
ينظّف المستندات القائمة.

> **الترتيب مهم**: شغّله بعد نشر التطبيق. لو شغّلته قبله، ستعيد النسخة
> القديمة كتابة الحقل عند أول حجز.

```bash
node scripts/strip_slot_patient_ids.js --dry-run
node scripts/strip_slot_patient_ids.js
```

`bookedCount` لا يُلمس — هو مصدر الحقيقة للإشغال.

## غير مؤتمت عمداً

لا شيء هنا يعمل كـ Cloud Function. كلها عمليات لمرة واحدة على بيانات إنتاج،
وتشغيلها يجب أن يكون قراراً واعياً بنسخة احتياطية جاهزة — لا حدثاً يقع من
تلقاء نفسه.
